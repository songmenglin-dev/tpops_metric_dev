1. **`decode.py`（83.5%）** —— 错误分支是主缺口：`DecodeError` 的各条路径、

   以及列名缺失 / 类型不符的报错分支。
3. **`rules_cross.py`（76.9%）** —— `ratio_across` 的**分母取不到 → 不产出**分支
   （M-3 裁决后的行为，M-3 涟漪那节说过这条要补守卫）、分母为 0 → 不产出、
   分子为 0 分母为正 → 产出 `0.0` 三种情形。
4. **`rules_sorting.py`（86%）** —— 排序的边界：单元素、空列表、
   排序列缺失、排序键类型混合。
5. 其余按行号逐条补。
