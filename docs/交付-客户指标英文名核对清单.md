# 客户指标英文名核对清单（客户交付版）

客户指标库的英文名来自**图片 OCR**，存在错字。本文稿列出疑似有问题的写法，**请客户逐条核对**并给出最终拼写；确认后我们只改映射表（表驱动），采集逻辑不动。

> - 数据来源：客户指标库 `高斯DB-指标明细（客户要求的应该要提供的指标明细）.xlsx`「指标库」sheet + `tpops_kafka_collector/mapping/data/metric_rules.json`
> - 生成方式：`python tools/build_delivery_docs.py`（重跑输出不变）

## 1. 现状与处理方式

- 采集端**按客户指标表的原文投递**（`metricCode` 就是表里的英文名，一个字都没改）。因此本文档「我们实际用的名字」一列与「客户表里的英文名」一列**目前完全相同**。
- 客户确认后，我们把 `metric_rules.json` 里对应规则的 `metric_code`（以及有问题的`metric_name`）改成建议写法，**代码不需要改**；届时「我们实际用的名字」才会与客户表产生差异。
- **本次核对没有发现取值口径错误**：98 个可提供指标的取数方式、维度、刷新周期都按映射表复核过，问题集中在**名称拼写**上。（单位口径另见第 8 节 —— 客户表里有几处「指标单位」与语义对不上，**待客户确认**。）

## 2. 判据

本文的清单由**两部分**组成，两部分**分开标注**（表里的「判据来源」列）：

| 部分 | 判据 | 覆盖范围 | 章节 |
|---|---|---|---|
| **自动判据命中** | 删字型 + 替换型（见下） | **英文名列**（客户指标库的「英文名」列） | 第 3 节 |
| **人工复核确认** | 逐字符人工比对 | **中文名列**（客户指标库的「中文名」列） | 第 4 节 |

**自动判据一：删字型**（脚本 `tools/build_delivery_docs.py` 的 `detect_ocr_findings`）：

1. 把指标英文名按 `.` / `_` 切成词；
2. 候选词表 = 全表 101 个指标名里的词 ∪ 本指标中文名里的词；
3. 某词若是候选词**删掉 1~2 个字符**得到的子序列，且差异**不是**英语屈折变化（-s / -es / -ed / -d / -ing / -n / -en），则判为疑似 OCR 缺字；
4. 候选词本身若又是别的词的截断，则不作候选（只保留最完整的写法）。

**自动判据二：替换型**（`detect_substitution_findings`）—— 某个词与语料里的另一个词**等长**且**只差 1 个字符**（`sequencial` → `sequential` 这类「换一个字母」的错误，删字型判据抓不到）。逐条人工复核结果见附录 B。

**人工复核**：上表两种自动判据都只是**候选**。本清单的每一条都**逐字符人工比对过**，「疑似问题」一列里的「第几位缺什么 / 第几位应该是什么」**由脚本逐字符算出来**，不是手写的。

> **覆盖面说明（别过读）**：自动判据只覆盖**英文名列**，且只覆盖「删字」与「换字母」两种形态；**中文名列**全部由人工逐字符核对（见第 4 节），英文名列也已逐条人工核对 —— 但自动判据**不能**证明「其余的都没问题」，只能说明「按上述两种形态没发现」。

「建议的正确拼写」一列是**建议**，最终以客户确认的为准。

## 5. 命名风格不一致（不影响取值，供一并确认）

以下不是 OCR 错字，而是**同一族指标内部的写法不统一**，会让 ITSCADA 台账按名字匹配时容易串。建议客户确认统一写法：

| 现象 | 例子 | 建议 |
|---|---|---|
| 分隔符混用 | `gaussdb.{#NAME}.Number.lete.ples`（点号）与 `GAUSSDB.Number_of_active_connections`（下划线） | 同一族统一用一种分隔符 |
| 大小写不一致 | `gaussdb.{#NAME}.Number.lete.ples`（`Number`）与 `gaussdb.{#NAME}.number.Of.index.scan`（`number`、`Of`） | 统一成一种大小写风格 |
| 同名指标两套写法 | 表级指标同时存在 `gaussdb.{#NAME}.…`（中文名描述）与 `GAUSSDB.{#NAME}.…`（英文名描述）两套 | 确认是两条独立指标，还是同一条的重复登记 |

## 8. 结论

- 客户指标库共 101 个指标；**16 个指标**的英文名或中文名疑似存在 OCR 错字（合计 37 处片段），其中英文名列 34 处、中文名列 3 处。
