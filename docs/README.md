## API 参考（`api/`）

`api/` 下的内容全部来自 CHM 的 **开发指南 › API参考 › API** 章节，为原文转换，未做增补或删改。

CHM 页面为 GB2312 编码，由 `tools/chm_to_md.py` 转换为 Markdown：

```bash
7z x "docs/06_GaussDB V2.0-26.861.1 产品文档(for 轻量化部署形态) 01.chm" -o/tmp/chm
python tools/chm_to_md.py /tmp/chm docs/api
```
