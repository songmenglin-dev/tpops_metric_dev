## ⚠️ 两套命名空间，不能混

| 命名空间 | 覆盖能力 | 本项目 |
|---|---|---|
| `/rds/v3/…` | 认证、实例列表、监控指标、指标目录、告警记录、告警统计 | ✅ |
| `/rds/gaussdb/v3/instances/{id}/…` | 数据库诊断优化接口集 + 统一命令中心 | ✅ |

少一段前缀就是 404（**不是「接口没实现」**）。
86 个客户指标靠 `/rds/gaussdb/v3/` 这一路 —— 去掉 `gaussdb` 段等于丢掉最大的一块。

> 各接口的**实测**请求/响应留档不在这里，在
> [`data/metric_response/`](../data/metric_response/)（逐指标原生响应）与
> [`data/command_center/`](../data/command_center/)（命令中心）。
> CHM 是契约，留档是事实，两者对不上时以留档为准。
